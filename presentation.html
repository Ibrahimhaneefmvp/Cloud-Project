NYC Taxi Analytics Engine

End-to-End Cloud Data Pipeline & ETL Presentation

1. Cloud Architecture Overview

Welcome to our end-to-end Data Engineering pipeline. This project ingests massive raw Parquet datasets of NYC Taxi logs and processes them entirely in the cloud, ensuring high performance, zero server management, and minimal cloud liabilities.

01 / 07

2. AWS S3: The Data Lake

We began by downloading the 2024 NYC Taxi Parquet dataset. Before uploading to our Amazon S3 Bucket, we recognized that pushing raw, dirty data into the cloud is an expensive mistake. We executed a strict local ETL process first.

02 / 07

3. The Great Data Cleansing

Using pandas and PyArrow, we aggressively filtered out anomalies to ensure dashboard integrity. We removed trips with negative fares, zero distances, extreme durations (> 4 hours), and impossible timestamps (dropoff before pickup).

  • Step 1: Filter invalid distances & fares
  • Step 2: Fix temporal anomalies
  • Step 3: Dedup identical pickup/dropoff logs

Result: A 100% pristine dataset ready for Athena.

03 / 07

4. Advanced Feature Engineering

A BI Engine is only as good as its features. We engineered highly optimized columns during the ETL phase to prevent expensive SQL operations in Athena later.

  • revenue_per_mile: Identifying high-value geographic routes.
  • tip_pct: Tracking customer generosity trends.
  • is_airport_trip: Flagging lucrative RatecodeID trips.
  • fare_category: Binning trips into Short, Medium, Long.
04 / 07

5. Amazon Athena: Serverless Querying

With our highly compressed, clean Parquet file uploaded to S3, we utilized AWS Athena. By defining our schema using the AWS Glue Data Catalog, Athena allows us to run complex SQL aggregations. Because we pre-engineered our features, query costs are effectively $0.

05 / 07

6. ODBC & Power BI: The Engine

To visualize the data, we bridged the cloud backend with our rendering engine. We configured an ODBC driver on our local system to securely tunnel into AWS Athena, calculating dynamic KPIs and geographic insights in Power BI.

06 / 07

7. The Premium Custom Frontend

To break free from Microsoft's licensing paywalls and deliver a true SaaS experience, we decoupled the frontend. We exported the optimized Power BI visuals and embedded them into this custom-built, Three.js-powered web application.
